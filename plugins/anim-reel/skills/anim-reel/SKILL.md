# AI 애니메이션 릴스

주제 한 줄 → 대본 → AI 목소리 → 장면별 애니메이션 → MP4. 렌더러는 HyperFrames(HTML + GSAP 타임라인을 프레임 단위로 찍음).

## 경로 약속
- `SK` = 이 SKILL.md가 있는 폴더. 모든 명령은 `node "<SK>/tools/reel.mjs" <명령>` 하나로 실행한다(아래 `RM`).
- `node`를 못 찾으면 설치 스크립트가 받아 둔 Node를 쓴다: Mac `~/.platformtree-skills/node/bin/node`, Windows `%USERPROFILE%\.platformtree-skills\node\node.exe`.
- 릴스는 **사용자가 연결한 작업 폴더**의 `릴스/<이름>/`에 만든다(`R`). 결과물은 `R/out/final.mp4`.
- 경로에 공백·한글이 있으니 항상 따옴표로 감싼다.

## 0. 환경 점검 (처음 한 번, 또는 오류가 나면)
`RM doctor` → ❌가 있으면 `RM doctor --fix` (렌더러·FFmpeg·렌더용 Chrome·uv·AI 목소리 도구를 관리자 권한 없이 설치).
- 받아쓰기 엔진은 **내 녹음·내 영상을 넣을 때만** 필요. 모델이 0.6~1.6GB라 받기 전에 사용자에게 묻고 `RM doctor --fix --whisper`.
- Node 22 미만이면 설치 명령을 다시 실행하라고 안내한다(README의 한 줄 설치).

## 1. 요청 파악 — 묻지 말고 기본값으로 시작
| 항목 | 기본값 | 바뀌는 경우 |
|---|---|---|
| 스타일 | `2d` (종이 질감 + 키네틱 자막 + UI 목업) | "3D", "입체" → `3d` |
| 목소리 | AI 목소리 `현수`(남), 속도 `+10%` | "여자 목소리" → `여자`, "남자" → `남자`(인준), 속도 말하면 `--rate` |
| 길이 | 30~45초 (문장 8~12개) | 사용자가 정하면 그대로 |
| 캐릭터 | 없음 | 사용자 사진을 주며 원하면 `references/character-guide.md` |

작업 폴더에 들어 있는 파일을 먼저 본다(`ls`). 파일 이름이 달라도 종류로 판단:
- **대본**(.txt/.md/.docx) → 그 대본을 그대로 쓴다(줄바꿈·강조만 정리).
- **참고 이미지**(.png/.jpg) → 색·분위기 참고, 또는 장면에 직접 넣는다(`R/assets/`로 복사 후 `<img>`).
- **촬영 영상**(.mp4/.mov) → **내 영상 모드**(4-C).
- **녹음 파일**(.m4a/.mp3/.wav) → **내 녹음 모드**(4-B).
사용자가 한 줄만 줬다면 바로 만든다. 정말 갈리는 것(예: 영상이 두 개)만 한 번 묻는다.

## 2. 새 릴스 폴더
`RM new <짧은-영문-이름> [--style 3d] [--in "<작업 폴더>/릴스"]` → 예제 프로젝트 복사 + 폰트·효과음 받기.
(`--in`을 빼면 현재 폴더의 `릴스/` 아래에 만든다. 현재 폴더가 사용자의 작업 폴더인지 확인할 것.)

## 3. 대본 → `R/script.md`, `R/timing.json`
- `references/script-formula.md`대로: 첫 문장 훅 → 핵심 2~3개 → 행동 유도. 사용자가 대본을 주면 그대로.
- `timing.json`의 `sentences`: 문장마다 `id`, `text`(청크는 ` / `로 나눔, 강조어는 `*단어*` 한 문장에 1~2개), `chap`(상단 라벨), `step`(오른쪽 위, 없으면 ""), `poses`(캐릭터 없으면 `[]`).
- 예제의 sentences·sfx는 예제 대본용이다. **새 대본으로 전부 바꾸고** 예제 장면을 그대로 두지 않는다.
- 대본에 없는 숫자·성과·후기를 지어내지 않는다. 확인 안 된 사실은 일반적인 표현으로.
- 고유명사·툴 이름은 `sttPrompt`에 적는다(받아쓰기 정확도).

## 4. 목소리 — 셋 중 하나
### 4-A. AI 목소리 (기본)
`RM voice R [--voice 현수|여자|남자] [--rate +10%]` → `R/voice/voice.mp3` + 단어별 시간 `words.json`(받아쓰기 불필요).
- 대본(`sentences`의 text)을 고치면 **반드시 다시** `RM voice R`.
- 무료 Microsoft Edge 낭독 음성(edge-tts)이라 API 키가 필요 없다. 실패하면 자동으로 최신 버전으로 한 번 더 시도한다. 그래도 실패하면 인터넷 연결을 확인하고, 직접 녹음(4-B)을 제안한다.
- 숫자·영어·기호 읽기가 어색하면(미리보기에서 확인) 그 부분만 소리 나는 대로 고쳐 쓰고 다시 만든다. 자막도 같이 바뀌니 화면에 꼭 보여야 하는 표기는 장면 카드에 넣는다.

### 4-B. 내 녹음
`RM record R <녹음 파일>` → `R/voice/raw_words.txt`를 대본과 맞춰 읽고 NG·중복 테이크를 찾아 `RM cut R --drop 시작-끝,…` (`references/voice-sync.md`).

### 4-C. 내 영상 (직접 찍은 말하는 영상)
1. `RM cam R <영상 파일>` → 영상을 `R/assets/cam_raw.*`로 복사, 소리를 뽑아 받아쓰기.
2. 대본이 없으면 `raw_words.txt`로 `sentences`를 만든다(말한 그대로).
3. `RM cut R [--drop …]` → 목소리와 영상이 **같은 구간으로** 잘린다(`assets/cam.mp4`, 세로 1080×1920으로 맞춤).
4. 문장마다 `"cam"`을 정한다: `"full"` = 영상 전체 화면(자막이 흰 글씨로 바뀜), `"pip"` = 아래쪽 둥근 작은 창, 없음 = 애니메이션만. 보통 **첫 1~2문장(훅)과 마지막 문장(행동 유도)은 `full`**, 설명 구간은 애니메이션 또는 `pip`.
   - `full` 문장에는 큰 장면 카드를 띄우지 않는다(영상을 가림). 작은 스티커·강조 정도만.
   - `pip` 문장의 장면은 화면 위쪽 460~1080px 안에 둔다(아래는 영상 창).

## 5. 장면 → `R/src/template.html`
- 위쪽 헬퍼·리그(자막·라벨·캐릭터·내 영상·전환)는 그대로 두고 `// ═════════ 장면` 블록만 새 대본에 맞게 다시 쓴다.
- 시각은 반드시 `S(i)`(문장 시작)·`E(i)`·`W(i, j)`(i번째 문장 j번째 단어 시작)로 — 목소리를 바꿔도 자동으로 따라온다.
- 2D: `references/scene-recipes.md`. 3D: `references/style-3d.md`. 화면 위쪽 168~440px은 자막 자리.
- 캐릭터가 없으면(기본) 장면을 500~1650px에 크게 써서 아래쪽이 비지 않게 한다. 예제 좌표는 캐릭터가 있을 때 기준이다.
- 문장마다 **그 말을 그림으로 보여 주는** 장면 하나(UI 목업, 숫자 카운터, 체크리스트, 비교, 아이콘). 글자만 다시 띄우는 장면은 피한다.

## 6. 효과음 → `timing.json`의 `sfx`
`{ "s": 문장, "w": 단어(-1=마지막 단어 끝), "off": 초, "name": "효과음 이름", "vol": 0.3~1 }`. **10초에 3~4개**, 장면의 핵심 순간에만. 목소리가 있으면 `sfxGain` 0.8. 매핑표: `references/sfx-guide.md`.

## 7. 빌드 → 스스로 검수 → 미리보기 → 완성
```
RM build R                 (목소리가 있으면 자동으로 단어 시간에 맞춤)
RM check R                 (lint + 문장마다 사진 1장 → R/out/snaps/contact-sheet*.jpg)
```
- contact sheet를 **Read로 열어** `references/qa-checklist.md` 기준으로 확인(글자 잘림·겹침·빈 화면·자막과 장면 충돌)하고 고친 뒤 다시. 사용자에게 보여주기 전에 스스로 고친다.
- `RM render R --draft` → `R/out/preview.mp4` 경로를 알려 주고 바꿀 점을 묻는다.
- 확정되면 `RM render R` → `R/out/final.mp4` (인스타그램 기준 음량 -14 LUFS로 맞춤).

## 8. 전달
- 결과 경로, 길이, 사용한 목소리, 다시 만들 때 바꿀 수 있는 것(스타일·목소리·속도·장면)을 짧게.
- AI 목소리를 썼다면: 인스타그램 업로드 때 **"AI 정보" 라벨**을 켜 두면 안전하다고 한 줄 안내.

## 하지 말 것
- GSAP 밖의 애니메이션(setTimeout, CSS transition/animation, Math.random) — 렌더러가 프레임을 되감아 찍으므로 재현이 안 된다. 난수는 `rnd(k)`.
- 레이아웃 속성(top/left/width) 트윈 — `x/y/scale`을 쓴다. `fromTo`를 같은 요소에 두 번 쓰면 두 번째부터 `immediateRender: false`.
- 효과음을 모든 움직임에 넣기, 같은 소리 3번 이상 반복, 그라데이션·글로우 범벅 같은 AI 느낌 장식.
- 대본을 고치고 목소리를 다시 만들지 않기(자막과 소리가 어긋남).
- 사용자 폴더 밖에 결과물을 두거나, 사용자의 원본 영상·녹음을 덮어쓰기(항상 복사본으로 작업).
