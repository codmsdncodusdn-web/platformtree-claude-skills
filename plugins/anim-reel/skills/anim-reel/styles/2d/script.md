# 릴스 대본 — 클로드 코드로 릴스 만들기 (댓글: 스킬)

녹음 팁
- 빈 줄 = 숨 한 번 (0.3초 정도). 줄바꿈은 그냥 이어서 읽으면 됩니다.
- 목표 길이 약 35초. 조금 빠르거나 느려도 괜찮아요. 녹음 파일을 주시면 영상 타이밍을 목소리에 맞춰 다시 맞춥니다.
- 문장 단위(S01~S13)로 끊어 읽으면 싱크 맞추기가 더 정확해져요.

---

[S01] 여러분, 이제 릴스도
직접 편집할 필요 없습니다.

[S02] 지금 보고 계신 이 영상도
클로드 코드로 만든 겁니다.

[S03] 목소리만 제가 녹음했습니다.

[S04] 방법도 진짜 간단합니다.
딱 2단계면 됩니다.

[S05] 첫 번째,
제가 공유해드릴 스킬 폴더를
클로드 코드에서 엽니다.

[S06] 그러면 클로드가
필요한 프로그램이 깔려 있는지
알아서 하나씩 확인해줍니다.

[S07] 두 번째,
만들고 싶은 영상을
딱 한 줄로 적습니다.

[S08] "인스타그램 수익화 노하우,
릴스로 만들어줘."

[S09] 그러면 클로드가
대본부터 장면, 자막, 효과음까지
알아서 다 만들어줍니다.

[S10] 좋은 건 여기서 끝이 아닙니다.

[S11] 다 만든 영상을
스스로 다시 보고
어색한 부분은 고쳐놓습니다.

[S12] 이제 릴스도
편집 프로그램이 아니라
한 줄로 만드는 시대입니다.

[S13] 📌 댓글에 스킬 남기시면
제가 실제로 쓰는 릴스 스킬이랑
설치 방법까지 보내드릴게요.

---
훅 대안
1. 여러분, 요즘 릴스 편집 알려준다면서 수십만 원씩 받는 곳 많습니다. 근데 이 스킬만 있으면 한 줄로 끝납니다.
2. 여러분, 이제 촬영 안 해도 이런 릴스 만들 수 있습니다.

댓글 키워드 후보: 스킬 / 릴스 / 클로드

가정한 것: 댓글로 나눠줄 자료는 "지금 쓰고 있는 reel-* 릴스 편집 스킬 + 설치 방법"으로 잡았습니다.
