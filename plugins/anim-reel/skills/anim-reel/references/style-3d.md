# 3D 스타일 장면 레시피 (`--style 3d`)

사용자가 "3D로", "입체로", "3D 애니메이션"이라고 하면 이 스타일로 만든다. 예제 `styles/3d/src/template.html`에 아래 장면이 모두 구현돼 있다. 새 릴스는 문장 성격에 맞는 장면 블록을 복사해 고친다. 2D와 데이터 구조(`timing.json`·`build.mjs`·`S/E/W/WE`)는 같다.

**진짜 입체(CSS 3D 변환)만 쓴다.** WebGL·three.js는 렌더러에서 프레임이 재현되지 않으므로 쓰지 않는다.

## 무대 구조
```
#scene (원근 1500px, 시점 540,760)
  └ #rig    영상 내내 아주 느린 흔들림 (건드리지 않음)
     └ #world  장면별 카메라 → camMove()
        ├ #floor   바닥 격자 (y=1180 높이의 수평면, 멀수록 흐려짐)
        └ #stage3d 3D 물체를 놓는 곳 (헬퍼 기본 parent)
#front   2D 위층 (말풍선·키캡·칩 — 카메라 영향 없음)
#cap     자막 168~440px
#trans   전환(wipe) 레이어
```
- 좌표: z=0 평면에서는 화면 픽셀과 1:1. `x,y`는 화면 좌표 그대로 쓰고, 깊이는 `z`(음수 = 멀리).
- 장면 영역: **캐릭터가 없으면 500~1650px** 띠를 쓴다(아래 절반이 비지 않게). 캐릭터가 있으면 500~1100px.
- 바닥선은 y≈1180. 물체 아래에 `shadow()`를 깔면 떠 있는 느낌이 산다.

## 헬퍼
| 헬퍼 | 하는 일 | 메모 |
|---|---|---|
| `extrude(글자, x, y, 크기, {w, color, side, back, depth, z})` | 두께 있는 글자 (뒤로 겹친 층) | 큰 키워드 전용. 한 화면에 1개. `rotationY`로 돌리면 옆면이 보임 |
| `card3d(x, y, w, h, {r, depth, bg, edge, border, z})` → `{o, face}` | 두께 + 그림자 있는 카드·창 | 내용은 `face`에, 움직임은 `o`에 |
| `cube(cx, cy, 크기, [앞,오른,뒤,왼,위,아래], {colors, z})` | 정육면체 | `rotationY: 기본값 - 90*k`면 k번째 면(0~3)이 앞으로 |
| `shadow(cx, y, w)` | 바닥 타원 그림자 | 물체와 같이 나타나고 사라지게 따로 트윈 |
| `show3d(o, t, from, dur, ease)` | 깊이에서 날아와 자리 잡기 | 최종 자세는 `o._rx/_ry/_rz/_z`에 미리 적어 둔다 |
| `hide3d(o, t, to, dur)` | 깊이로 물러나며 사라지기 | |
| `camMove(t, {rotationX, rotationY, z, x, y}, dur, ease)` | 카메라(=#world) 이동 | 궤도는 ±25도 안. 장면 끝나면 0으로 되돌린다 |
| `wipe(t)` → 덮인 시각 | 노란 블라인드가 3D로 뒤집히는 전환 | 반환 시각에 이전 장면 `autoAlpha:0`. 영상당 1~2번 |
| `show/hide/pop/draw/counter` | 2D와 같음 | `#front`의 2D 요소에 |

## 장면 레시피 (예제에 구현됨)
| 문장 성격 | 장면 | 포인트 |
|---|---|---|
| 훅·주제 키워드 | 바닥에서 솟는 `extrude` 큰 글자 + 그림자, 천천히 좌우 회전 | 키워드 단어 `W(i,j)`에 솟음. 다음 장면 전에 깊이 속으로 사라짐 |
| 명령·입력 | `card3d` 창이 깊이에서 날아옴 + 말하는 속도로 타이핑 + Enter 키캡(`#front`) | 글자 = 해당 단어 시작~끝 |
| 여러 항목 나열 | 카드 3장을 부채꼴(rotationY ±30, 양옆 z -140)로, 단어마다 하나씩 | 강조어에서 차례로 한 바퀴(`rotationY: '+=360'`) |
| "깊이·입체·돌면서" | 가운데 카드는 앞으로(z +240) 양옆은 뒤로(z -420) + `camMove` 좌→우 궤도 | 시차가 깊이를 보여 줌 |
| 단계 1→2→3 | `cube` 면마다 STEP, 단계 단어에서 90도씩 회전 | `back.inOut` 회전이 손맛 |
| "다 모으면 / 한 줄이면" | 작은 큐브 3개가 위에서 떨어져 착지(`bounce.out`) + 아래 한 줄 입력 카드 + 체크 | 착지 = 단어 시작 |
| CTA | `wipe` → `extrude` 키워드(화면에서 가장 큼) + 흰 댓글 카드 + 도는 선물 큐브 + DM 카드 | 키워드는 댓글 단어에 |

## 하지 말 것
- WebGL·three.js·canvas 애니메이션, CSS animation/transition, `Math.random`(→ `rnd(k)`), setTimeout.
- 글로우·네온·무지개 그라데이션 같은 AI 느낌 장식. 빛은 그림자로만 표현한다.
- 카메라를 계속 크게 돌리기(멀미). 기본 흔들림은 `#rig`이 하고, `camMove`는 장면당 1번 정도.
- `#stage3d` 안 물체를 `top/left/width`로 움직이기 → `x/y/z/rotation*`/`scale`만.
- 같은 요소에 `fromTo` 두 번이면 두 번째부터 `immediateRender: false`.
- `extrude`를 한 화면에 2개 이상, 또는 너무 긴 문장에 (층 수 × 글자 수만큼 무거워짐). 6~7글자, 크기 150~460px.
- 강한 회전 상태(±60도 넘게)에서 글자를 읽게 하기 — 읽어야 할 순간엔 정면에 가깝게.
