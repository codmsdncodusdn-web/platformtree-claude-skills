# 내 녹음·내 영상 넣기: NG 자르기 → 싱크 → 립싱크

`RM` = `node "<스킬 폴더>/tools/reel.mjs"`, `R` = 릴스 폴더. 내 영상이면 1단계를 `RM cam R <영상>`으로 한다(소리를 뽑아 받아쓰고, 3단계 `cut`이 영상도 같은 구간으로 자른다).

## 1. 원본 받아쓰기
```
RM record R <녹음 파일>      (timing.json의 sttPrompt에 고유명사·툴 이름을 적어 두면 받아쓰기가 정확해진다)
```
`R/voice/raw_words.txt`(줄 번호·시각·문장)를 `script.md`와 나란히 놓고 읽는다. 대본이 없으면(내 영상만 준 경우) 이 받아쓰기로 `timing.json`의 sentences를 만든다(말한 그대로, 오탈자만 고침).

## 2. 잘라낼 구간 찾기
- **중복 테이크**: 같은 문장을 두 번 말함 → 마지막 테이크만 남기고 앞을 버린다.
- **말실수·끊긴 말·"다시 할게요"**: 버린다. 의미 있는 말은 지우지 않는다.
- **받아쓰기의 거짓 반복**: whisper는 실제로 한 번 말한 문장을 두 번 적기도 한다. 쉼으로 확인:
  ```
  ffmpeg -hide_banner -nostats -i R/voice/raw.m4a -af silencedetect=noise=-35dB:d=0.18 -f null -
  ```
  말소리 덩어리 길이가 문장 길이(초당 약 6음절)보다 짧으면 반복이 아니다. 의심 구간만 잘라 다시 받아써 본다(`ffmpeg -ss A -t L -i raw.m4a part.wav` → `node <스킬>/tools/transcribe.mjs part.wav part.json`).
- **다른 사람 목소리(아이 등)·잡음**: 사용자에게 들었는지 묻거나, 스펙트로그램에서 화자의 기본 주파수(남성 약 100~200Hz, 여성 약 180~300Hz)와 다른 높은 배음(300~600Hz 간격)이 따로 뜨는 짧은 덩어리를 찾는다. 단어와 겹치지 않는 구간만 자른다.
- **환각**: 파일 끝 뒤의 "감사합니다" 같은 단어는 `transcribe.mjs`가 자동으로 버린다.

## 3. 자르고 쉼 조이기
```
RM cut R --drop 50.8-53.8,20.72-20.855
```
쉼은 0.26초 이하로 줄어 늘어지지 않는다. 컷마다 8ms 페이드라 클릭 잡음이 없다. 잘린 파일을 다시 받아써 모든 문장이 한 번씩, 순서대로 있는지 확인한다(다음 단계 build가 자동으로 받아쓴다). 내 영상이면 `assets/cam.mp4`도 같은 구간으로 잘려 목소리와 맞는다.

## 4. 싱크
```
RM build R
```
- 대본 ↔ 받아쓰기를 **글자 단위로 정렬**(오탈자는 그 자리에서만 어긋남).
- 문장 경계는 받아쓰기 경계에서 가장 가까운 **실제 쉼**에 붙인다: 앞 문장 끝 = 쉼 시작, 다음 문장 시작 = 쉼 끝. 문장 안 단어는 그 구간으로 비례 이동(끝부분 시간 밀림 보정).
- 출력된 문장 시각이 서로 겹치지 않고, 마지막 문장이 녹음 길이 안에서 끝나는지 확인.

## 4-1. 배속 (예: 1.1배)
영상 파일을 빠르게 돌리면 프레임이 빠져 움직임이 끊긴다. 대신 목소리만 빠르게 하고 다시 맞춘다.
1. `R/voice/voice.m4a`(컷 편집된 원래 속도)를 `R/voice/voice_1x.m4a`로 이름 바꾸기
2. `timing.json`에 `"voiceSpeed": 1.1` (끝 여백 `tail`도 2.0 정도로)
3. `RM build R` → 받아쓰기·쉼 분석은 원래 속도 녹음으로 하고 시간만 1.1로 나눈다. 재생용 `voice.m4a`는 음높이를 유지한 채 자동으로 다시 만들어진다(atempo).
빠른 녹음에서 쉼을 다시 찾으면 짧은 쉼이 감지 기준 아래로 사라져 문장 경계가 틀어지므로, 분석은 항상 원래 속도로 한다.

## 5. 립싱크
`RM build R`가 프레임마다 입 모양을 계산한다.
- 음절 모음으로 모양: ㅏ 크게 벌림, ㅗ·ㅜ 오므림, ㅣ·ㅡ 옆으로 납작, ㅔ·ㅐ 중간. ㅁ·ㅂ·ㅍ에서 입술 닫힘.
- 목소리 크기(프레임 RMS)로 벌림 정도 — 소리가 없으면 입이 닫힌다.
- 포즈마다 그려진 입을 피부색 패치로 덮고 그 위에 같은 화풍의 입을 그린다(`assets/char/mouths.json`).
검수: 얼굴만 잘라 여러 시점을 모아 본다.
```
RM check R --at 2.2,8.6,16,20.3,29,41   (사진: R/out/snaps)
ffmpeg -i out/snaps/frame-00-at-2.2s.png -vf crop=300:270:395:1370 face0.png   (프레임마다)
```
입꼬리 옛 선이 비치면 `template.html`의 패치 `rect` 크기를 키운다.
