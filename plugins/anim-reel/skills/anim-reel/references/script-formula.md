# 대본 공식

## 기본 흐름 (30~50초, 130~230어절)
| 순서 | 역할 | 예시 |
|---|---|---|
| 훅 | "여러분,"으로 시작하는 선언 | 여러분, 이제 릴스도 직접 편집할 필요 없습니다. |
| 증거 (선택) | 지금 보는 게 결과물 | 지금 보고 계신 이 영상도 클로드 코드로 만든 겁니다. |
| 간단 선언 | 부담 낮추기 | 방법도 진짜 간단합니다. 딱 2단계면 됩니다. |
| 단계 | 최대 2단계, 실제 동작으로 | 첫 번째, 스킬 폴더를 클로드 코드에서 엽니다. |
| 결과 | 구체적으로 3개 나열 | 대본부터 장면, 자막, 효과음까지 |
| 한 방 더 (선택) | 추가 이점 1개 | 좋은 건 여기서 끝이 아닙니다. |
| 마무리 (선택) | "~하는 시대입니다" | 이제 릴스도 한 줄로 만드는 시대입니다. |
| CTA | 📌 댓글 키워드 → 자료 | 📌 댓글에 스킬 남기시면 … 보내드릴게요. |

## 훅 틀
- 안 해도 된다형: 여러분, 이제 [번거로운 일]도 직접 안 하셔도 됩니다.
- 결과 먼저형: 여러분, 이제 [평범한 것]도 [고급 결과물]처럼 만들 수 있습니다.
- 가격 반전형: 여러분, 요즘 [이거] 알려준다면서 수십만 원씩 받는 곳 많습니다. 근데 이 방법만 알면 바로 됩니다.
- 이 영상도형: 여러분, 지금 보고 계신 이 영상, 편집 하나도 안 했습니다.
- 숫자형: 여러분, [결과]까지 딱 [N]단계면 됩니다.

## 문체
- "~습니다" 체. CTA 마지막만 "보내드릴게요". 호칭 "여러분", 나는 "제가".
- 한 줄 2~6어절, 문장 사이 빈 줄 = 숨 한 번.
- 하지 말 것: 과장 형용사(혁신적인·놀라운), 질문형 훅, 3단계 이상, 중간 CTA, 근거 없는 숫자.

## timing.json으로 옮기기
- 한 문장 = `sentences` 한 항목. 자막은 ` / `로 나눈 청크 단위로 두 줄까지 쌓인다(약 26자 넘으면 다음 화면).
- 강조어 `*단어*`는 문장당 1~2개. 숫자·결과·핵심 명사.
- 숫자 "2단계"는 받아쓰기에서 "이단계"로 나와도 자동으로 맞춰진다.
