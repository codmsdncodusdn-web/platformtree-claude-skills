# 장면 레시피

예제 `styles/2d/src/template.html`에 아래 장면이 모두 구현돼 있다. 새 릴스는 문장 성격에 맞는 장면을 골라 블록을 복사·수정한다.

| 문장 성격 | 장면 | 포인트 |
|---|---|---|
| "~할 필요 없습니다" | 편집 프로그램 카드 위 빨간 마커 X (`draw` 두 획) | X는 핵심 단어 `W(i,j)`에 |
| "이 영상도" | 폰 목업 안에 지금 영상의 축소판 + 터미널 칩 + 빨간 알약 | 자기 참조라 바로 이해됨 |
| "제가 녹음" | 녹음 카드 + 움직이는 파형 + REC 깜빡임 | 사람 냄새 |
| "딱 N단계" | 점선 칸 → 검은 숫자 타일(`pop`) → 타일이 오른쪽 위 STEP 배지로 이동 | 장면이 이어져 보임 |
| 설치·점검 | 터미널 체크리스트(스피너 → 체크) + 빨간 "준비 완료" 도장 | 체크 시각을 말하는 단어에 |
| 한 줄 입력 | 입력창에 말하는 속도로 글자가 찍힘 + Enter 키캡 | 글자 = 해당 단어의 시작~끝 |
| "알아서 만들어줍니다" | 폰 와이어프레임 + 제작 패널(항목별 스피너→체크) + 진행률 | 항목 완료 = 해당 단어 |
| 반전·추가 | `halftone()` 전환 → 검은 보너스 카드 | 전환은 영상에서 2번까지 |
| 품질 점검 | 점수 카드 5.1 → 9.2 (`counter`), 약한 막대에 빨간 동그라미(`handCircle`) | |
| 비교 | 왼쪽 X 카드 / 오른쪽 빨간 테두리 카드 | |
| CTA | 큰 빨간 키워드 알약 + 댓글창 + DM 카드 | 키워드가 화면에서 가장 큼 |

## 좌표·레이어
- 캔버스 1080×1920. 자막 168~440px, 장면 460~1150px, 캐릭터 1100px~.
- **캐릭터가 없으면(기본)** 아래가 비지 않게 장면을 **500~1650px** 범위에 크게 쓴다: 카드·창은 세로로 키우고(높이 800px 이상), 중심을 y≈1050에 둔다. 예제 좌표는 캐릭터가 있을 때 기준이니 그대로 쓰지 말 것.
- **내 영상 pip 문장**은 아래 영상 창(약 1100~1800px)을 비워 두고 460~1080px 안에 장면을 둔다.
- `stage`(캐릭터 뒤) / `front`(캐릭터 앞) / `marks`(마커 SVG) 레이어.
- 카드는 `wrap(x,y,w,h,radius)` → 하프톤 점 그림자 자동. `o._rot`로 1~4도 기울이기.
