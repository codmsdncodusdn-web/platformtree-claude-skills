# 검수 체크리스트 (스냅샷을 Read로 열어 확인)

- [ ] 첫 1초 안에 훅 자막과 첫 효과음
- [ ] 자막이 두 줄을 넘지 않고, 캐릭터 얼굴을 가리지 않음
- [ ] 빨간 강조어는 문장당 1~2개
- [ ] 장면이 비어 있는 구간(그래픽 없음)이 1초 넘게 이어지지 않음
- [ ] 화면이 3초 넘게 멈춰 있지 않음
- [ ] 마커 선·도장이 그려지기 전에 미리 보이지 않음 (빨간 점이 남아 있으면 `draw` 확인)
- [ ] 이전 장면 요소가 캐릭터 뒤에 남아 있지 않음 (퇴장 트윈에 `autoAlpha: 0`)
- [ ] 포즈가 바뀔 때 머리 위치가 튀지 않음
- [ ] (녹음 후) 문장이 말하는 순간에 바뀌고, 입이 말할 때만 움직임
- [ ] (녹음 후) 효과음이 목소리를 덮지 않음 — 이어폰 + 폰 스피커로 사용자에게 확인 요청
- [ ] CTA 키워드가 화면에서 가장 크고, 자동 DM 키워드와 같음
- [ ] 최종 음량 -14 LUFS, 피크 -1 dBTP 이하 (`ffmpeg -i out/final.mp4 -af ebur128=peak=true -f null -`)
